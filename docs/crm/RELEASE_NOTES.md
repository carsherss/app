# CRM Pages preview release notes

## Preview scope

- Eight static CRM routes for operations overview, bookings, employees, customers, services, payments, audit and settings.
- Seeded synthetic sample dataset with a fixed 2 November 2026 anchor date.
- Local-only booking status and employee assignment interactions.
- Responsive navigation, theme switch, data banner and accessible semantic controls.
- GitHub Actions build artifact for pull requests and GitHub Pages deployment from `main`.

## Explicitly outside this release

- Customer or employee authentication
- Live API, database or CRM persistence
- SMS/OTP delivery
- Payment processing or refunds
- Real-time employee tracking or dispatch
- Production customer records

This is an internal static preview, not a production operations system.
