# Operations notes

- Use GitHub Issues for scoped tasks and pull requests for changes.
- Keep `main` deployable; use branches such as `feat/customer-booking`.
- Test APKs on physical Android devices before a pilot.
- Record app version and commit SHA for each internal build.
- Debug APKs are for internal testing only.
- Free-tier services may sleep, impose limits, or change terms. Verify current quotas and data retention before choosing production providers.
